# 月ごとメモ

月ごとに「何のジャンルにいくら使った/得たか」を見るための、シンプルな家計メモWebアプリです。

普通の家計簿のように毎日の細かい日付管理をするのではなく、  
「今月、本にいくら使ったか」「食事にいくら使ったか」「収入はいくらあったか」をすぐに見られることに絞っています。

## Demo

https://ring128.github.io/monthly-money/

## 特徴

- 月単位で支出・収入を管理
- 日付と月は入力時に自動保存
- 初期ジャンルなし
- 支出ジャンル・収入ジャンルを自分で追加
- 今月の支出、収入、差額を表示
- ジャンル別に合計金額を表示
- ジャンルを押すと、そのジャンルの入力内容を確認
- 過去の月別差額、年別合計を確認
- 年間ジャンル割合を円グラフで表示
- JSONでバックアップ/復元
- 広告なし
- ログインなし
- バックエンドなし

## コンセプト

このアプリは「毎日きっちり家計簿をつける」ためのものではありません。

月ごとに、ざっくりと

- 何に使っているか
- どこから収入があるか
- 今月の差額はいくらか

を把握するためのシンプルなツールです。

## 使用技術

- TypeScript
- HTML
- CSS
- Vite
- localStorage
- GitHub Pages
- PWA

Reactやバックエンドは使わず、TypeScript中心で実装しています。

## データ保存について

データはブラウザの `localStorage` に保存されます。  
サーバーには送信されません。

ブラウザのデータを削除すると記録も消えるため、必要に応じてJSONバックアップを使います。
